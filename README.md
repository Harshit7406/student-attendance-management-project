# Student Attendance Management System

## Project Overview
A Student Attendance Management System implemented using MongoDB.
It stores student, faculty, course, enrollment, and attendance data.

## Technologies Used
- MongoDB
- MongoDB Compass
- JavaScript / MongoDB Shell

## Database Collections
- users
- students
- faculty
- courses
- enrollments
- attendance

## Implemented Features
- Database and collection creation
- Sample data insertion
- CRUD operations
- Student-wise attendance percentage
- Course-wise attendance statistics
- Identification of students below 75% attendance
- Daily attendance summaries
- Absent-student reports
- Index creation and verification

## How to Run
1. Install MongoDB Server and MongoDB Compass.
2. Connect to the local MongoDB server.
3. Open the MongoDB Shell.
4. Run the required sections of `mongodb_queries.js` individually.
5. Verify the results using the aggregation and index queries.

**Warning:** The sample-data section may clear existing documents if its reset commands are enabled. Review the commands before running them.
